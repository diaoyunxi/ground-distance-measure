# 地面测距仪 · 多焦距摄像头

用手机摄像头测量现实世界的地面长度：标定**单位距离**，在移动过程中**实时计算距起点的距离**，最终同时给出**起止点直线距离**与**摄像头移动的曲线距离**。

支持同一台手机上的**多个不同焦距摄像头**（主摄 / 超广角 / 长焦 / 前置），每个镜头独立标定。

---

## 功能

| 能力 | 说明 |
| --- | --- |
| 多摄像头枚举 | 通过 `enumerateDevices()` 列出全部视频输入，识别主摄 / 超广角 / 长焦 / 前置 |
| 单位距离标定 | 地面放置已知尺寸参考物（A4 纸等），点选 4 角 → 解算该镜头的米/像素比例 |
| 焦距解算 | Zhang 单平面标定，两条约束联立，避免单约束退化 |
| 相机位姿 | 单应分解求相机位置与高度，实时反投影任意像素到地面 |
| 实时测距 | 移动过程中实时显示「距起点距离」与「曲线里程」 |
| 曲线里程 | Shi-Tomasi 角点 + 逆组合 Lucas-Kanade 光流 + 帧间单应 → 位姿累积 |
| 双距离输出 | 起止点直线距离 与 摄像头实际移动曲线距离，并给出绕行系数 |

## 使用流程

1. **选择镜头** —— 顶部下拉框列出所有可用摄像头。
2. **标定** —— 在地面平放参考物（默认 A4 纸），点「开始标定」，依次点选 **左上 → 右上 → 右下 → 左下** 四个角。
   标定完成后界面显示解算焦距、视场角、相机高度与重投影误差。
3. **选起点** —— 点击画面中的起点位置。
4. **移动测量** —— 点「开始移动测量」，然后**保持手机朝向不变地平移**。
   界面实时显示距起点的距离、单位距离与已走过的曲线里程。
5. **选终点** —— 到达目标后点击画面中的终点位置，输出最终结果。

> 画面下方的蓝色比例尺标注了**当前视野中心处 1 米对应的像素长度**，可直观核对尺度是否合理。

## 精度与注意事项

- 标定质量由重投影误差评估（RMS < 2px 为优秀）。误差大时四角贴合不准，请重新标定。
- **透视影响**：地面尺度随距离变化，画面越靠上（远处）米/像素越大。界面显示的是画面中心处的尺度。
- **测量期间请保持手机姿态（俯仰/旋转）尽量稳定**，姿态突变会导致帧间特征点大量丢失、里程中断。
- 曲线里程依赖光流跟踪，画面需要足够的地面纹理（地砖、纹理、标识线等）；纯色地面跟踪效果差。
- 镜头切换或改变变焦后有效焦距会变化，**必须重新标定**。
- 该工具输出的是参考物所在**平面**上的距离，地面不平坦时会产生系统误差。

## 技术实现

全部算法为自研纯 TypeScript 实现，**零运行时依赖**，无 OpenCV 等原生库。

```
src/core/
├── linalg.ts        3x3 矩阵运算、线性方程组、对称矩阵 Jacobi 特征分解
├── homography.ts    归一化 DLT、LO-RANSAC 鲁棒估计、退化检测
├── camera.ts        焦距解算、单应分解求位姿、地面投影与距离
├── calibration.ts   标定流程、单位距离、直线距离、结果汇总
├── odometry.ts      灰度化、Shi-Tomasi 角点、逆组合 LK 光流、曲线里程
└── devices.ts       摄像头枚举与能力探测
```

关键算法说明：

- **单应求解**：Hartley 归一化 + DLT（最小奇异向量）。共线点集显式判为退化。
- **鲁棒估计**：LO-RANSAC。最小样本 4 点 + 留出验证 + 局部优化重拟合。
  4 点最小解存在"巧合解"歧义，靠留出验证与内点中位数误差联合判优。
- **焦距解算**：Zhang 单平面标定的正交约束 `h1ᵀωh2=0` 与等模约束 `h1ᵀωh1=h2ᵀωh2`
  联立求解。当地面 X 轴垂直光轴时正交约束退化（分母为零），必须依赖等模约束兜底。
- **位姿双解**：平面单应存在"相机在上/在下"两个解，通过翻转第三基向量选取相机位于地面上方的解。
- **光流**：逆组合 Lucas-Kanade + 3 级图像金字塔，可处理较大位移。

## 开发

```bash
npm install
npm run dev        # 本地开发服务器
npm run typecheck  # TypeScript 类型检查
npm run test       # 单元测试（Vitest，68 项）
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

## CI

`.github/workflows/ci.yml` 在 push / PR / tag 时自动执行：

1. TypeScript 类型检查
2. 单元测试
3. 构建 —— **失败自动重试，最多 5 次**，直至构建成功
4. 上传构建产物（artifact）
5. `main` 分支额外自动部署到 GitHub Pages

## 浏览器要求

需要支持 `getUserMedia` 与 `enumerateDevices` 的现代浏览器（Chrome / Edge / Safari 16+）。
摄像头需通过 HTTPS 或 localhost 访问。
