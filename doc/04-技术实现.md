## 技术实现

全部算法为自研纯 TypeScript 实现，**零运行时依赖**，无 OpenCV 等原生库。

```
src/core/
├── linalg.ts        3x3 矩阵运算、线性方程组、对称矩阵 Jacobi 特征分解
├── homography.ts    归一化 DLT、LO-RANSAC 鲁棒估计、退化检测
├── camera.ts        焦距解算、单应分解求位姿、地面投影与距离
├── calibration.ts   标定流程、单位距离、直线距离、结果汇总
├── odometry.ts      灰度化、Shi-Tomasi 角点、逆组合 LK 光流、曲线里程
└── devices.ts       摄像头枚举与能力探测
```

关键算法说明：

- **单应求解**：Hartley 归一化 + DLT（最小奇异向量）。共线点集显式判为退化。
- **鲁棒估计**：LO-RANSAC。最小样本 4 点 + 留出验证 + 局部优化重拟合。
  4 点最小解存在"巧合解"歧义，靠留出验证与内点中位数误差联合判优。
- **焦距解算**：Zhang 单平面标定的正交约束 `h1ᵀωh2=0` 与等模约束 `h1ᵀωh1=h2ᵀωh2`
  联立求解。当地面 X 轴垂直光轴时正交约束退化（分母为零），必须依赖等模约束兜底。
- **位姿双解**：平面单应存在"相机在上/在下"两个解，通过翻转第三基向量选取相机位于地面上方的解。
- **光流**：逆组合 Lucas-Kanade + 3 级图像金字塔，可处理较大位移。
