## 功能

| 能力 | 说明 |
| --- | --- |
| 多摄像头枚举 | 通过 `enumerateDevices()` 列出全部视频输入，识别主摄 / 超广角 / 长焦 / 前置 |
| 单位距离标定 | 地面放置已知尺寸参考物（A4 纸等），点选 4 角 → 解算该镜头的米/像素比例 |
| 焦距解算 | Zhang 单平面标定，两条约束联立，避免单约束退化 |
| 相机位姿 | 单应分解求相机位置与高度，实时反投影任意像素到地面 |
| 实时测距 | 移动过程中实时显示「距起点距离」与「曲线里程」 |
| 曲线里程 | Shi-Tomasi 角点 + 逆组合 Lucas-Kanade 光流 + 帧间单应 → 位姿累积 |
| 双距离输出 | 起止点直线距离 与 摄像头实际移动曲线距离，并给出绕行系数 |
